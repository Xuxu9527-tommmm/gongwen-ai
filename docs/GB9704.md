# GB/T 9704-2012《党政机关公文格式》版式参数速查

> 公开国家标准，导出 Word/PDF 时的确定性参数。以下为常用要点速查，
> 完整规范以标准原文为准（https://openstd.samr.gov.cn）。

## 页面

| 项 | 值 |
|---|---|
| 纸张 | A4（210mm × 297mm），竖排 |
| 页边距 | 上 37mm、下 35mm（版心下边缘）、左 28mm、右 26mm |
| 每页 | 22 行 × 每行 28 字（指定撑满版心） |

## 字体字号

| 元素 | 字体 | 字号 | 说明 |
|---|---|---|---|
| 份号 | 阿拉伯数字 | 3号 | 版心左上角第一行 |
| 密级和保密期限 | 黑体 | 3号 | 份号下方 |
| 发文机关标志（红头） | 小标宋体 | 不超过22mm×15mm | 红色，上边缘至版心上边缘 35mm（上行文 35mm 于版心上边缘之下） |
| 发文字号 | 仿宋 | 3号 | 年份用六角括号〔〕；下行文居中，上行文左空一字、右侧留签发人 |
| 红色分隔线 | — | — | 发文字号之下 4mm，与版心等宽 |
| 标题 | 小标宋体 | 2号 | 红线下空二行；可分一行或多行，回行时词意完整、梯形或菱形排列 |
| 主送机关 | 仿宋 | 3号 | 标题下空一行，顶格，全角冒号 |
| 正文 | 仿宋 | 3号 | 每段首行左空二字 |
| 一级标题「一、」 | 黑体 | 3号 | 末尾不加标点（除句号外） |
| 二级标题「（一）」 | 楷体 | 3号 | 括号后不写顿号 |
| 三级标题「1.」 | 仿宋 | 3号 | 可加粗 |
| 附件说明 | 仿宋 | 3号 | 正文下空一行，左空二字："附件：1. ×××" |
| 落款（发文机关署名） | 仿宋 | 3号 | 成文日期之上；右空二字（加盖印章时按印章规则调整） |
| 成文日期 | 阿拉伯数字 | 3号 | 右空四字；如「2026年3月5日」不补前导零 |
| 页码 | 宋体 | 4号半角数字 | 左右各空一字；奇数页右空一字、偶数页左空一字；数字两侧一字线 |

## 行距

正文行距按"每页 22 行撑满版心"折算，Word 常用**固定值 28.8 磅**（3号字）。
A4 版心高 = 297 − 37 − 35 = 225mm ≈ 637.8 磅；637.8 / 22 ≈ 29 磅，
实际排版以撑满为准，28.8 磅是通用近似值。

## 习惯性错误（核稿规则来源）

- 发文字号年份用 `[]` 或 `【】` → 必须六角括号 `〔〕`
- 成文日期用汉字数字或补零（"二〇二六年"、"03月05日"）→ 必须阿拉伯数字、不补零
- 标题末尾加句号 → 不加
- 层次序号跳级 → 一、→（一）→ 1. →（1）
- （一）后加顿号 → 不加（括号本身就是层级标记）
